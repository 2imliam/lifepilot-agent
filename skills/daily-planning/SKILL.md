# Daily Planning Skill

## Workflow
1. Read user tasks and deadlines.
2. Check available time blocks.
3. Prioritize urgent and important tasks.
4. Create a realistic schedule.
5. Leave buffer time between tasks.
6. Ask for confirmation before creating reminders.
